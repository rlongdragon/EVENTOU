# EVENTOU LOGO

兩張疊在一起的票：前面是白底黑框、黑色 E、橘色票根，後面斜放一張橘色票。

| 檔案                          | 用途                             |
| ----------------------------- | -------------------------------- |
| `eventou-mark.svg`            | 彩色版，放在紙色、白色或深色底上 |
| `eventou-mark-mono-ink.svg`   | 單色墨色版，放在淺色或橘色底上   |
| `eventou-mark-mono-paper.svg` | 單色紙色版，放在深色或橘色底上   |

- 畫布為正方形 112 × 112，可直接當分頁圖示或頭像。
- 顏色與 `frontend/src/index.css` 的主題變數相同：墨色 `#1c211f`、紙色 `#f8f6f1`、橘色 `#e5652a`。
- 彩色版不要放在橘色底上，後面那張票會看不見；改用單色版。
